Measuring surprise

1Information content

How surprised should you be when something happens? Information content turns that into a number.

The information content (or surprisal) of an outcome x with probability p(x) is

I(x) = log 1p(x) = −log p(x)

Rare outcomes carry a lot of information and certain ones carry none. The base of the logarithm sets the unit: base 2 gives bits, base e gives nats, and 1 nat ≈ 1.443 bits. The toggle at the top switches every number on this page.

The logarithm is there for one reason: information from independent events should add. If x and y are independent then p(x, y) = p(x)p(y), and only a logarithm turns that product into a sum.

I(x, y) = −log p(x)p(y) = I(x) + I(y)

A useful reading: I bits is about the number of yes/no questions needed to single out one outcome among 2I equally likely ones.

2Entropy

Entropy is the average surprise of a distribution.

Average the information content over the distribution itself:

H(P) = Ex∼P[ −log p(x) ] = −∑x p(x) log p(x)

with the convention 0 log 0 = 0. Entropy measures how uncertain you are before seeing a sample. It is also the best possible compression: no code can use fewer than H(P) bits per symbol on average, and good codes get within one bit of it (Shannon's source coding theorem).

  • H ≥ 0, and H = 0 only when one outcome has probability 1.
  • For K outcomes, H ≤ log K, with equality only for the uniform distribution.
  • 2H (in bits) is the effective number of outcomes: a distribution that is as uncertain as a fair k-sided die has 2H = k.

3Entropy of random variables

The entropy of a random variable depends only on its distribution, not on the values it takes.

We write H(X) for the entropy of the distribution of X. Relabeling the outcomes, say X → 2X + 1, changes nothing, because only the probabilities enter. Some standard cases:

  • Bernoulli(p): H = −p log p − (1−p) log(1−p), largest (1 bit) at p = ½.
  • Geometric(p): H = HBern(p) / p.
  • Binomial(n, p) and Poisson(λ) have no tidy closed form, but for large parameters they approach ½ log(2πe·variance).

For a continuous variable with density f, the analogue is the differential entropy h(X) = −∫ f log f dx. It is not the limit of discrete entropy: it can be negative, it changes under rescaling (h(aX) = h(X) + log|a|), and chopping X into bins of width Δ gives H(XΔ) ≈ h(X) − log Δ. For a Gaussian,

h(N(μ, σ²)) = ½ log(2πeσ²)

and among all densities with a given variance the Gaussian has the largest differential entropy.

Two variables

4Joint entropy

The uncertainty of a pair, treated as one variable.

H(X, Y) = −∑x,y p(x, y) log p(x, y)

It satisfies max(H(X), H(Y)) ≤ H(X, Y) ≤ H(X) + H(Y). The upper bound is tight exactly when X and Y are independent. The gap is the mutual information, the amount the two variables share:

I(X; Y) = H(X) + H(Y) − H(X, Y)

Notation warning: H(X, Y) with random variables is joint entropy, while H(P, Q) with two distributions (section 6) is cross entropy. The lab below sends a symbol X through a noisy channel: with probability ρ the output Y copies X, otherwise Y is a fresh draw from the same distribution.

5Conditional entropy

What uncertainty is left in X once you know Y?

H(X|Y) = ∑y p(y) H(X|Y=y) = −∑x,y p(x, y) log p(x|y)

It is the average, over y, of the entropy of the conditional distribution. The chain rule splits a joint entropy into steps:

H(X, Y) = H(Y) + H(X|Y) = H(X) + H(Y|X)

On average, conditioning never hurts: H(X|Y) ≤ H(X), with equality iff X and Y are independent. But for one particular y, H(X|Y=y) can be larger than H(X). A surprising observation can leave you less sure than before. The average still comes out no larger.

Comparing distributions

6Cross entropy

The cost of describing data from P with a code built for Q.

Entropy is the best average code length when the code matches the data. Suppose the data really come from P but you built your code for a model Q, so outcome x costs −log q(x). The average cost is the cross entropy:

H(P, Q) = Ex∼P[ −log q(x) ] = −∑x p(x) log q(x)

It is never smaller than H(P), and the excess is exactly the KL divergence of section 8:

H(P, Q) = H(P) + DKL(P ‖ Q)

This is the standard classification loss. The label is a one-hot distribution P, the network's softmax output is Q, and the cross entropy collapses to −log qy, the negative log-likelihood of the correct class. It is not symmetric: H(P, Q) ≠ H(Q, P) in general.

7Perplexity

Cross entropy, exponentiated into something you can picture: a number of choices.

The perplexity of a distribution is eH, which equals 2H when H is in bits. It is the effective number of equally likely outcomes. For a language model Q scored on a test sequence x1, …, xN:

PP = exp( −1N ∑t ln q(xt | x<t) ) = exp H(p̂, q)

where p̂ is the empirical distribution of the test data. Equivalently, it is the inverse geometric mean of the probabilities the model gave to what actually happened. A model that guesses uniformly over V tokens has PP = V; a model that is never surprised has PP = 1. Lower is better. Because the base cancels, perplexity is the same whether you compute it in bits or nats.

8KL divergence

The extra cost of using Q when the truth is P.

DKL(P ‖ Q) = ∑x p(x) log p(x)q(x) = EP[ log p(x) − log q(x) ] = H(P, Q) − H(P)

For densities, replace the sum by ∫ dx. Four things to remember:

  • Not symmetric. D(P‖Q) ≠ D(Q‖P), and the triangle inequality fails, so it is a divergence and not a distance.
  • Support matters. If q(x) = 0 where p(x) > 0, the divergence is infinite.
  • Terms can be negative individually, but the total never is (section 11).
  • It is zero exactly when P = Q.

KL divergence in depth

9Interpreting KL divergence

Two readings of the same number: wasted bits, and accumulated evidence.

  • Extra code length. Encoding samples from P with a code designed for Q costs D(P‖Q) more bits per symbol than the code designed for P.
  • Evidence per sample. If data truly come from P, the expected log-likelihood ratio log p(x)/q(x) in favor of P is D(P‖Q). After n samples the likelihood ratio grows like enD, which is why the error rate of the best test between P and Q decays at rate D (Stein's lemma).
  • Information gained. If Q is a prior and P is the posterior after an update, D(P‖Q) is how much the update taught you.

The first two are the same quantity seen two ways. For one symbol x, the bits wasted by using Q's code are −log q(x) − (−log p(x)) = log p(x)/q(x), which is the log-likelihood ratio. The lab below plots the running total of that quantity on random samples.

10KL between two Gaussians

One of the few cases with a clean closed form, and the one behind the VAE loss.

For P = N(μ1, σ1²) and Q = N(μ2, σ2²), in nats:

DKL(P ‖ Q) = ln σ2σ1 + σ1² + (μ1 − μ2)²2σ2² − 12
Derivation

Start from D = EP[ln p(x) − ln q(x)]. Each log-density is −½ ln(2πσ²) − (x−μ)²/(2σ²). Under P, E[(x−μ1)²] = σ1² and E[(x−μ2)²] = σ1² + (μ1−μ2)². Substituting:

−½ ln(2πσ1²) − ½ + ½ ln(2πσ2²) + σ1² + (μ1−μ2)²2σ2²

and the first and third terms combine into ln(σ2/σ1).

Two special cases are worth memorizing. With equal variances it reduces to (μ1−μ2)²/(2σ²), half the squared distance in standard deviations. With Q = N(0, 1) it becomes ½(μ² + σ² − 1 − ln σ²), the regularizer in a VAE. In d dimensions: ½[tr(Σ2−1Σ1) + (μ2−μ1)ᵀΣ2−1(μ2−μ1) − d + ln(det Σ2 / det Σ1)].

11Non-negativity of KL divergence

D(P‖Q) ≥ 0, with equality only when P = Q (Gibbs' inequality).

Proof 1, from ln x ≤ x − 1. Sum over outcomes with p(x) > 0:

−D = ∑ p ln qp ≤ ∑ p ( qp − 1 ) = ∑ q − ∑ p ≤ 1 − 1 = 0

Proof 2, Jensen. Because −ln is convex, E[−ln X] ≥ −ln E[X]. Take X = q(x)/p(x) with x drawn from P:

D = EP[ −ln qp ] ≥ −ln EP[ qp ] = −ln ∑p>0 q ≥ 0

Equality needs q/p to be constant, which forces P = Q. Several facts follow at once: H(P, Q) ≥ H(P); H(P) ≤ log K (apply it with Q uniform); and I(X; Y) ≥ 0, since mutual information is the KL divergence between the joint and the product of marginals, so H(X|Y) ≤ H(X).

12KL divergence and maximum likelihood

Fitting a model by maximum likelihood is minimizing a KL divergence.

Let x1, …, xN be data and p̂ their empirical distribution. The average log-likelihood of a model qθ regroups as an expectation under p̂:

1N ∑i log qθ(xi) = Ep̂[ log qθ ] = −H(p̂, qθ) = −H(p̂) − D(p̂ ‖ qθ)

H(p̂) does not depend on θ, so

argmaxθ log-likelihood = argminθ H(p̂, qθ) = argminθ D(p̂ ‖ qθ)

As N grows, p̂ approaches the true distribution P*, so MLE converges to the model closest to P* in the forward direction D(P* ‖ qθ). If the model family contains P*, that is P* itself. If not, it is the best approximation in that specific sense, which is the subject of the next section.

13Forward vs reverse KL

Which argument comes first decides what the best approximation looks like.

Approximate a target P with a simpler family Q. There are two ways to measure the mismatch.

  • Forward D(P‖Q) averages over P. It explodes wherever P has mass and Q does not, so the best Q is mass-covering (zero-avoiding). This is MLE. For a Gaussian Q the optimum matches the mean and variance of P.
  • Reverse D(Q‖P) averages over Q. It explodes wherever Q has mass and P does not, so the best Q is mode-seeking (zero-forcing). It is what variational inference minimizes, and it can have several local optima.
