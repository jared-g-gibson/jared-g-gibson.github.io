Gaussian & Bernoulli mixture models

A mixture model says every point was generated by secretly picking one of K sources, then sampling from that source. Try it below.

Formally, each point $x_i$ has a hidden (latent) label $z_i \in \{1,\dots,K\}$ that you never observe. First $z_i$ is drawn from the mixing weights $\pi$, then $x_i$ is drawn from component $z_i$'s distribution:

p(x) = Σk πk · p(x | θk),   Σk πk = 1
  • Gaussian mixture (GMM): each component is a Gaussian $\mathcal{N}(\mu_k, \sigma_k^2)$ — natural for continuous data.
  • Bernoulli mixture (BMM): each component is a set of independent coin flips, one per dimension — natural for binary data (binarized pixels, yes/no features).
  • Because $z_i$ is unobserved, plain maximum likelihood is intractable in closed form, so we fit with Expectation–Maximization (EM): the E‑step computes soft responsibilities $p(z_i=k\mid x_i)$ for every point under the current parameters; the M‑step refits $\pi,\mu,\sigma$ (or $\pi,\mu_{kd}$ for Bernoulli) as weighted averages using those responsibilities.
  • EM only climbs to a local optimum — the likelihood surface is non-convex, so initialization and restarts matter.
  • Unlike k-means, membership is soft: a point gets a probability of belonging to each cluster, not a hard label.

Bias–variance tradeoff for classification

Same toy dataset, one knob — the number of neighbors k in k-NN — controlling model complexity.

Error splits (roughly) into two sources:

  • Bias: systematic error from a model too rigid to represent the true pattern (underfitting).
  • Variance: error from being too sensitive to the particular training sample you happened to draw (overfitting).

Small $k$ → low bias, high variance, jagged boundary that memorizes noise. Large $k$ → high bias, low variance, an over-smoothed boundary. The same logic applies to tree depth, polynomial degree, or regularization strength in any classifier.

Classification has a twist regression doesn't: only which side of the boundary a point lands on matters. Variance far from the boundary is harmless; variance right at the boundary flips predictions. So classifiers often tolerate messier internal estimates than regressors do, as long as the boundary stays roughly right.

Bagging (random forests) averages many high-variance models to cancel variance. Boosting chains many high-bias weak learners to drive down bias.

Probabilistic graphical models

A graph that factors a big joint distribution into small local pieces.

Directed (Bayesian networks):

p(x1,…,xn) = Πi p(xi | parents(xi))

Undirected (Markov random fields):

p(x) = (1/Z) Πc ψc(xc)

Reading independence off a directed graph uses d-separation. Click node B below in each structure.

A node's Markov blanket — its parents, children, and children's other parents — is the smallest set that makes it independent of everything else. It's exactly what you need to resample a node in Gibbs sampling.
